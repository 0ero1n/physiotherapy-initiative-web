# Tanzania Physiotherapy Initiative - Web Application (Next.js)

A modern, high-performance web application recreated in Next.js 16 (App Router), TypeScript, and Tailwind CSS for the **Tanzania Physiotherapy Initiative**.

## 🌟 Tech Stack
- **Framework**: Next.js 16 (App Router + Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 + Curated Brand Design System
- **Icons**: Lucide React
- **Typography**: Google Fonts (Montserrat for headings, Inter for body text)

## 🎨 Brand Design Tokens
- **Primary Color**: `#696112` (Dark Olive Gold)
- **Secondary Color**: `#8B8B3A` (Medium Olive)
- **Surface**: `#F8F9FA`
- **Accent**: `#A0A04A` / `#D4AF37`

## 🚀 Getting Started

### 1. Installation
Navigate into the project directory and install dependencies:
```bash
cd ~/Documents/React/physiotherapy-initiative-web
npm install
```

### 2. Development Server
Start the local Next.js development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
Build and run the optimized production bundle:
```bash
npm run build
npm start
```

## 📱 Page Overview
- **Home (`/`)**: Hero section with logo, Dr. Elia Swai mission quote, core values cards, impact stats, program highlights, and training preview.
- **About Us (`/about`)**: Organizational narrative, mission & vision cards, leadership team profiles with high-resolution photos, and values breakdown.
- **Our Approach (`/approach`)**: Four core initiative pillars (Tanzania Physiotherapy Academy, Summer School, International Exchanges, Innovation Incubation) and an interactive training photo gallery slider with modal lightbox.
- **Strategic Partners (`/partners`)**: Categorized directory of academic institutions, referral hospitals (e.g. Bugando, Muhimbili, KCMU), international NGOs (AMREF), and interactive category filter.
- **Contact Us (`/contact`)**: Live validated contact form, Kinondoni office location details, phone, email, and operating hours.
- **Donate & Support (`/donate`)**: Multi-currency donation portal supporting Tanzanian Mobile Money (Vodacom M-Pesa, Tigo Pesa, Airtel Money, HaloPesa) and Card/International payments, with preset amounts and impact transparency breakdown.
